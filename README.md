# 🐻 Code Bear

**Code Bear** é um jogo educacional desenvolvido como parte do Trabalho de Conclusão de Curso do Tecnólogo em Sistemas para Internet.  
O objetivo do projeto é ensinar **conceitos básicos de programação e raciocínio lógico** de forma **lúdica e interativa**, utilizando elementos de **gamificação** e **desafios matemáticos**.

## 🎯 Objetivo do Projeto

O jogo busca facilitar o aprendizado inicial de programação, estimulando o pensamento lógico por meio de desafios progressivos, feedbacks visuais e mecânicas de recompensa.  
Ele foi projetado especialmente para **crianças de 7 a 8 anos**, com uma interface acessível e colorida, inspirada em jogos educativos modernos.

---

## 🕹️ Como Jogar

1. Na tela inicial, clique em **Jogar**.  
2. Escolha uma **fase** disponível.  
3. Monte a **sequência de comandos** clicando nas setas (→ ↑ ↓ ←) para guiar o personagem até a **bandeira**.  
4. Ao completar a fase, será apresentado um **desafio de matemática** (adição ou subtração).  
   - Acertando, o jogador ganha **moedas**!  
5. Use as moedas para **comprar novos personagens** na **Loja**.

---

## 🧩 Funcionalidades Principais

- 🧠 Desafios progressivos de lógica e matemática  
- 🐾 Movimentação do personagem por sequência de comandos  
- 🏳️ Sistema de fases e bandeiras  
- 💰 Loja para desbloquear personagens com moedas  
- 💬 Feedback imediato para o jogador  
- 🖥️ Interface responsiva e acessível

---

## 🛠️ Tecnologias Utilizadas

- **GameMaker Studio 2** – desenvolvimento do jogo e lógica de programação  
- **Canva** – design de telas, ícones e elementos visuais
